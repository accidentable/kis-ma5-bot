# 한 달 대회 전략 — 전종목 16년 탐색과 봇 적용 (2026-09-28)

## 한 줄 결론

**KRX 전종목 16년(상장폐지 포함)으로 166개 설정을 돌렸지만, 시장을 확실히 이기는 한 달 전략은 없었다.**
사전에 정한 검증 절차를 끝까지 통과한 **52주 신고가 근접 로테이션**을 봇에 넣었다.
이 전략의 한 달 기대값은 **+0.2 ~ +0.9%(시장 수준 또는 조금 낮음)** 이다. 그래도 예전 MA5 규칙(한 달 −4 ~ −8%)보다는 훨씬 낫다.

## 시뮬레이션 조건 ("60만원 · 한 달" 대회 흉내)

- **한 달 = 21거래일.**
  - 첫날 시가에 매수한다 (전날 종가까지의 신호로).
  - 마지막 날 종가에 전량 매도한 것으로 보고 수익률을 잰다.
  - 시작일을 2 ~ 3일씩 밀어가며 수백 개 구간을 만들었다.
- **계좌:** 60만원, 정수 주식(원주가 기준), 슬롯당 60만/k 원. 비싸서 못 사는 종목은 다음 순위로 넘긴다.
- **비용 (편도):** 매도세 0.20%, 수수료 0.015%, 슬리피지 max(0.05%, 0.5틱).
  - 시가 상한가로 열린 날은 못 산다고 봤다.

## 검증 절차 (실행 전에 고정)

1. **IS (2011 ~ 2018):** 계열마다 2슬롯 한 달 평균이 가장 높은 설정 하나를 고른다.
2. **VAL (2019 ~ 2024.9):** 계열 대표끼리 비교한다.
3. **TEST (2024.10 ~ 2026.9):** VAL 상위 3개를 한 번만 본다.

## 결과

### 1차 — 9계열 114설정

- **계열:** 모멘텀, 52주 신고가 근접, 단기 반전, 주도주 눌림, 거래대금 돌파, 저변동, 소형, 상한가 추종, MAX 회피 모멘텀
- **유니버스:** 시총 상위 200 / 201 ~ 1000위 / 거래대금 30억 이상 전부

| 계열 대표 (2슬롯) | IS | VAL | TEST |
|---|---|---|---|
| 시장 (거래대금 30억↑ 동일가중, **비용 전**) | +0.7% | +1.9% | +2.9% |
| **52주 신고가 근접, 시총 상위 200, 21일** | **+0.5%** | **+0.9%** | **+0.9%** |
| 모멘텀 120일, 시총 상위 200 | +1.2% | +0.2% | −2.4% |
| 주도주 눌림 (2차 추천 ①) | +0.8% | −1.1% | - |
| 단기 반전 | −0.5% | −1.3% | - |
| 거래대금 돌파 | −0.4% | −0.8% | - |
| 저변동 | +0.4% | +0.1% | −0.1% |
| 소형 (거래대금 30억↑) | +1.4% | (−10%↓ 31%로 탈락) | - |

- **IS 최고가 그대로 유지되지 않는다:** IS 에서 좋던 모멘텀·소형은 VAL·TEST 에서 무너졌다. 한국 시장은 모멘텀이 약하다는 기존 연구(George & Hwang 2011)와 같은 결과다.
- **앞서 3.4년 데이터로 추천했던 "주도주 눌림"은 16년 데이터에서 탈락했다 (VAL −1.1%).** 3.4년 결과는 강세장과 생존편향 덕이었다.

### 2차 — 조사 기반 24설정

- **후보:** WorldQuant 101 알파 #19·#24 (흔히 "골드만 퀀트"로 불리는 공개 알파), 저변동·저MAX·단기반전 합성, 고베타.
- **결과:** 어느 것도 VAL·TEST 에서 시장을 넘지 못했다.
  - 합성(시총 201 ~ 1000위)이 VAL +1.9%로 시장과 같았지만 IS −0.3%, TEST +0.9%였다.
- **지수 대용:** KOSPI200 ETF 대용(시총 가중)은 IS 0.0%, VAL +0.4%, TEST +5.2%였다.
  - 대회에서 ETF 수익이 인정되는지 확인하지 못해 봇에 넣지 않았다.
  - 레버리지 ETF는 기본예탁금 1,000만원·사전교육 조건 때문에 60만원 계좌로는 못 산다.

### 수급 (기관·외국인 순매수) — 28설정, 2019 ~ 2024

- **선택 구간(2019.7 ~ 2021)에서는 좋았다:** 기관 5일 순매수 ÷ 시총 상위 2종목이 한 달 +2.3%.
- **검증 구간(2022 ~ 2024.11)에서는 −1.4%로 무너졌다.** 외인+기관 합산도 −1.2%였다.
- 같은 종목 집합의 합성 전략(수급 없음)은 검증 구간에서 +2.1%였다. 수급을 더하면 오히려 나빠졌다.
- **조사 결과도 같은 방향이다:** 수급은 당일 수익률과는 상관이 강하지만, 다음 날 이후를 예측하는 힘은 약하고 국면에 따라 뒤집힌다.

## 봇에 넣은 전략

**52주 신고가 근접 로테이션** (`STRATEGY=near_high`, 기본값)

- **유니버스:** 코스피+코스닥 보통주 시총 상위 200.
  - 관리·정지·경고 종목을 뺀다.
  - 주가 1,000원↑, 20일 평균 거래대금 10억↑, 60일 수익률 > 0 인 종목만 남긴다.
- **순위:** 전일 종가 ÷ 250거래일 최고가. 슬롯 금액(30만원)으로 1주도 못 사는 종목은 순위에서 뺀다.
  - 이 필터 유무로 16년 결과에 차이가 없었다.
- **매매:** 상위 2종목을 반반 사서 21거래일 보유한다.
  - 교체일엔 순위 밖으로 밀린 종목만 팔고 새로 산다.
  - 손절·익절은 없다 (손절은 검증하지 않았다).

### 민감도 (선택 뒤 점검, `lab_sens_nearhigh.md`)

- **변형해도 결과가 −1.5% ~ +2.8% 사이에서 시장 수준을 오간다.** 시총 상위 100/300, 120일 최고가, 1·3종목, 10일 교체로 바꿔봤다.
- **특정 설정에만 기대는 결과는 아니지만, 우위도 없다.**
- **10일마다 교체는 확실히 나빴다.** 자주 사고팔수록 비용만 늘어난다.

## 한계

- **초과수익은 기대하지 마라.** 이 전략의 한 달은 "대형주 2종목을 들고 있는 한 달"과 거의 같다.
- **대회 순위:** 상위권은 운에 가깝다. 이 전략으로 +10%를 넘길 확률은 5번 중 1번 정도다.
- **2종목 집중이라 변동성이 크다.** 한 달 −10% 이하가 8 ~ 16%.
- **데이터 한계:**
  - marcap 수정주가는 한투와 최대 2.8% 다르다.
  - 수급 데이터는 2019 ~ 2024 · 1,275종목뿐이다.
  - 장중(분봉) 전략은 검증하지 못했다.

## 배포 (서버에 옮기기만 하면 된다)

`.env` 는 건드릴 필요 없다. `STRATEGY` 가 없으면 `near_high` 로 돈다.

- **기존 보유:** `data/state.json` 은 그대로 두면 된다. 예전 MA5 보유 종목이 있으면 첫 교체(다음 09:05) 때 순위 밖이면 팔린다.
- **DRY_RUN:** 서버 `.env` 값을 그대로 따른다. 실주문이면 첫 09:05 에 2종목을 실제로 산다.

```bash
# PC (저장소)
git fetch origin backtest-universe-iofw7v && git checkout backtest-universe-iofw7v
tar czf bot.tgz --exclude=.git --exclude=data --exclude=.venv --exclude=.env \
    cli.py config.py core jobs handlers tests requirements.txt .env.example README.md infra
scp bot.tgz <user>@211.233.200.43:/tmp/

# 서버
sudo systemctl stop ma5-bot
cd /opt/ma5-bot && tar xzf /tmp/bot.tgz
./.venv/bin/python tests/test_rotation.py      # 통과 34 / 실패 0 이어야 한다
./.venv/bin/python cli.py check                # 설정 요약에 "52주 신고가 근접" 이 보이면 정상
./.venv/bin/python cli.py scan                 # (선택) 오늘 순위만 계산, 주문 없음, 3~5분
sudo systemctl start ma5-bot
```

**배포 시각별 첫 매수**

| 배포 시각 | 첫 매수 |
|---|---|
| 08:20 전 | 08:20 에 순위 계산 → 09:05 에 매수 |
| 08:20 ~ 09:05 | 09:05 에 순위를 새로 계산한 뒤 매수 |
| 장중 | 다음 10분 감시가 교체를 실행 (14:30 까지) |

**되돌리기:** `.env` 에 `STRATEGY=ma5` 를 넣고 재시작한다.
