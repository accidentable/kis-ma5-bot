# MA5 돌파 역발상 봇 (STRATEGY=ma5)

5일 이동평균선 아래에 머물던 KOSPI100 종목이 5일선을 위로 넘으면 전액 매수하고,
+3% 익절·5일선 이탈·보유기간 중 먼저 닿는 조건에서 청산한다. 청산으로 슬롯이 비면
장중에도 다시 들어간다 — 하루에 여러 번 회전할 수 있다.

---

## 전략

### 진입 — 매일 09:05, 조건을 모두 만족하는 1종목

| # | 조건 | 왜 |
|---|------|-----|
| 1 | 직전 5거래일 중 3일 이상 종가가 그날의 5일선 아래 | "5일선 아래에서 놀던" 상태 확인 |
| 2 | 전일 종가 < 전일 5일선 | 어제까지도 눌려 있었다 |
| 3 | **현재가 > 직전 4거래일 종가 평균** | 지금 5일선을 위로 넘었다 |
| 4 | 전일 종가 대비 상승률 ≤ 5% | 이미 급등한 건 추격하지 않는다 |
| 5 | **20일선 > 60일선** (골든크로스 상태) | 하루 반등으로 60일선을 잠깐 넘는 하락추세 종목을 거른다 |
| 6 | 20일 평균 거래대금 ≥ 30억 | 전액 주문을 소화할 유동성 |

조건 3이 5일선 돌파와 같은 말인 이유:

```
오늘 5일선 = (C₁+C₂+C₃+C₄+P)/5      C₁~C₄ = 직전 4거래일 종가, P = 현재가

P > (C₁+C₂+C₃+C₄+P)/5
  ⟺ 5P > C₁+C₂+C₃+C₄+P
  ⟺ 4P > C₁+C₂+C₃+C₄
  ⟺ P > (C₁+C₂+C₃+C₄)/4
```

장중에는 오늘 종가가 없어서 5일선이 확정되지 않는다. 위 변형 덕분에
**직전 4일 종가 평균 하나만 있으면** 현재가로 즉시 판정할 수 있다.
청산 조건인 5일선 이탈도 부등호만 뒤집으면 된다.

### 종목 선정 — 후보가 여럿이면 점수 1위 하나만

| 지표 | 의미 | 가중치 |
|---|---|---|
| **squeeze** | 5·20·60일선 수렴도 — (최고−최저)/주가. 이평선이 한 점에 모일수록 ↑ | **1.0** |
| **contraction** | ATR(5)/ATR(20) — 봉이 작아지며 조여들수록 ↑ | **0.7** |
| depth | 전일 이격도가 낮을수록 ↑ (깊이 눌렸다 올라옴) | 0.3 |
| thrust | 돌파 강도 | 0.5 |
| trend | 20일선/60일선 이격 — 추세 강도 | 0.3 |
| value | 20일 평균 거래대금 | 0.3 |

**"수렴 후 발산" 자리를 1순위로 두는 이유.** 상승추세 종목이 눌리면서 고점은 내려오고 저점은 올라와
삼각형으로 조여들면, 이평선이 한 점에 모이고 봉이 작아진다. 그 꼭짓점에서 5일선을 뚫는 건 새 파동의
시작이고, 벌어진 이평선 사이를 오르내리는 돌파와는 질이 다르다. `squeeze` 가 이평선 뭉침을,
`contraction` 이 봉 크기 축소를 잰다.

골든크로스 발생일(`cross_age`)은 참고 정보로만 계산한다. 횡보장에선 이평선이 계속 교차해서
크로스 자체는 노이즈라, 랭킹에는 쓰지 않는다.

각 지표를 후보 집단 내 백분위로 환산한 뒤 가중합한다. 절대값이 아니라 상대순위라
지표 간 단위 차이에 영향받지 않는다.

### 청산 — 먼저 닿는 것

| 조건 | 판정 시점 | 기준 | 매도 지정가 |
|---|---|---|---|
| **+3% 익절** | 장중 감시 (10분 간격) | 진입가 +3% | 현재가 −1틱 (급할 게 없다) |
| 5일선 **급이탈** | 장중 감시 | 현재가 < 5일선 **− 1×ATR** | 현재가 −2틱 |
| 5일선 이탈 | 마감 정리(15:15) | 현재가 < 5일선 | 현재가 −2틱 |
| 3거래일 경과 | 마감 정리(15:15) | — | 현재가 −2틱 |

**장중과 종가의 이탈 기준이 다른 이유.** 5일선은 종가로 만드는 선이다. 그걸 10분마다 장중 틱과 그대로
비교하면 하루 ±1–2% 잡음이 전부 '이탈' 로 잡혀, 5일선을 막 넘은 자리에서 사서 살짝 밑도는 자리에서
파는 −1% 손절이 반복된다 (실제로 첫 두 거래가 −1.15%, −1.16% 로 그렇게 끝났다). 그래서 장중엔
5일선보다 **1×ATR(대형주 기준 2–3%) 아래**까지 내려가야 이탈로 치고, 종가엔 원래 규칙대로 본다.
`INTRADAY_MA5_ATR_BUFFER=0` 으로 두면 예전처럼 장중에도 5일선 그대로 판정한다.

### 장중 재진입 — 슬롯이 비면 다시 들어간다

08:40 준비 작업에서 1차 필터를 통과한 종목(보통 20–30개)을 **그날 캐시**해둔다. 1차 조건은
전일 종가로 확정되므로 장중에 바뀌지 않는다. 이후 10분 감시 때마다 슬롯이 비어 있으면
캐시된 종목의 **현재가만 조회**해 돌파를 다시 판정한다 — 일봉을 다시 받지 않으니 25초면 끝난다.

| 규칙 | 값 | 이유 |
|---|---|---|
| 허용 시간 | 09:10 ~ 14:30 | 개장 직후 잡음 구간과, 사봐야 움직일 시간이 없는 오후는 뺀다 |
| 당일 매매 종목 | 재진입 금지 | 익절한 종목은 여전히 5일선 위라 같은 판정으로 더 비싸게 되산다 |
| 09:05 작업과 겹침 | 잠금으로 배제 | 스케줄러가 스레드풀이라 09:05 작업이 길어지면 09:10 감시와 겹칠 수 있다 |

`INTRADAY_REENTRY=false` 로 끄면 예전처럼 09:05 한 번만 들어간다.

### 하루 일정

| 시각 | 작업 | 비고 |
|---|---|---|
| 08:40 | 일봉 99종목 → 1차 후보 계산·캐시 | 느린 작업(유량제한 2–3분)을 개장 전으로 |
| 08:50 | 프리마켓(KRX+NXT 통합→NXT) 가격으로 돌파 판정 → 1순위에 **눌림 대기 주문 1건** | 지정가 = 프리마켓가 **− 0.5ATR**. 동시호가부터 유효 |
| 09:00–10:00 | 대기 주문이 **장 초반 급락**을 기다린다. 여기까지 빠지면 체결 | 08:50 에 못 걸었으면 09:05 대체·10분 재진입도 같은 방식(현재가 − 0.5ATR) |
| 09:10–09:50 | 10분 감시. **익절만** 본다 | 급이탈·손절은 10:00 까지 유예 |
| **10:00** | 안 빠졌으면 취소 → **현재가로 한 번에 매수**. 체결됐으면 확정 | 이 시각부터 급이탈·손절 발동. 이후 재진입은 즉시 매수 (–14:30) |
| 15:15 | 미체결 취소, 종가 5일선 이탈·3거래일 만료 청산, 리포트 | |

**장 초반엔 빠질 때 산다 (`PREOPEN_OFFSET_ATR=-0.5`).** 수렴 구간은 이평선이 뭉쳐 있어 개장 직후
변동성이 크고, 특히 장 초반에 훅 빠지는 일이 잦다 — 그 자리가 진입 기회였다는 관찰에서 나온 규칙이다.
그래서 10:00 전의 모든 진입(08:50 선주문, 09:05 대체, 10분 재진입)은 즉시 매수가 아니라
**기준가 − 0.5ATR 지정가를 걸어두고 급락을 기다린다.** 08:50 주문은 동시호가부터 유효하므로 시가가 그
아래로 서면 시가에 채워지고, 아니면 장 초반 눌림에 채워진다. 10:00 까지 안 빠지면 취소하고 그 자리에서
현재가로 한 번에 산다. 10:00 이후 진입은 처음부터 현재가다.

ATR 은 최근 14일 평균 하루 고저폭으로 대형주는 주가의 2–3% — 0.5ATR ≈ 1.3% 다. 급이탈선(5일선 − 1ATR)
보다는 항상 위에 걸리므로, 눌림에 사자마자 급이탈로 나가는 구조는 아니다. 눌림을 더 깊게 기다리려면
−0.8, 얕게 잡으려면 −0.3 으로 둔다.

**08:50 에 판정하는 이유.** NXT 프리마켓(08:00–08:50)에서 코스피100 대부분이 이미 거래되므로 개장 전에
"5일선을 넘었는가" 를 볼 수 있고, 대기 주문을 동시호가부터 걸어둘 수 있다.

**손절 유예(`STOP_BLACKOUT_UNTIL=1000`).** 개장 한 시간의 흔들림에 팔지 않으려고 급이탈·손절을 10:00 까지
보지 않는다. 익절은 본다. 대신 갭다운은 10:00 까지 그대로 안고 간다 — 이 설계가 감수하는 꼬리다.

**선주문을 분할하지 않는 이유(`SPLIT_TRANCHES=1`).** 아래로 여러 건 걸어두면 진짜 슈팅(안 눌림)엔 1차만
채워지고 실패한 돌파(눌림)엔 전량 채워진다 — 맞을 땐 작게, 틀릴 땐 크게. 수렴→발산 전략과 정면으로
충돌한다. 분할 인프라는 남겨뒀고 `SPLIT_TRANCHES=3`, `SPLIT_CANCEL_AT=1000` 으로 켤 수 있다.
ATR 은 최근 14일 평균 하루 고저폭으로 대형주는 주가의 2–3% 다 — `SPLIT_STEP_ATR=0.5` 면 한 단 아래가 약 −1.3%.

- **손절선은 없다.** 5일선 이탈이 유일한 방어선이다. 갭하락은 그대로 맞는다.
  넣으려면 `.env` 에 `USE_STOP_LOSS=true`, `STOP_LOSS_PCT=3` 을 추가하면 된다.
- 5일선 기준가는 매일 아침 갱신된다. 진입 당시 값을 고정해두면 청산 판정이 틀어진다.
- 보유일차는 진입일이 1일차다. `MAX_HOLD_TRADING_DAYS=3` 이면 3일차 장 마감에 정리된다.

### 포지션

**1종목 × 100%.** 분산이 없으므로 한 종목의 악재가 곧 계좌 전체다.
`MAX_POSITIONS` / `POSITION_PCT` 로 조정할 수 있다.

매수 수량은 한투의 **미수없는매수수량**을 기준으로 잡는다. 미수(증거금 대출)를
쓰면 반대매매 위험이 생기고 대회 수익률 계산이 꼬인다.

### 유니버스를 마스터파일에서 뽑는 이유

한투가 공개하는 `kospi_code.mst` 에 **KOSPI100 편입 플래그**가 그대로 들어있다.

파싱은 고정폭 문자열 슬라이싱이라 pandas도 필요 없다. **런타임 의존성은 `requests` 하나**이고,
그래서 람다 배포 패키지가 몇 MB에 그친다.

## 운영 방식

### A. 서버 1대 상주 — 권장 (네이버 클라우드 Micro Server 등)

```bash
python cli.py serve
```

이 한 줄이 전부다. APScheduler 가 09:05 진입 / 장중 10분 감시 / 15:15 마감을 KST 로 돌리고,
같은 프로세스 안에서 텔레그램 **롱폴링** 스레드가 명령을 받는다.

롱폴링이라 **공개 엔드포인트도, 인바운드 포트도 필요 없다.** 서버가 텔레그램 쪽으로
나가는 연결만 쓴다. 웹훅을 안 쓰니 `getUpdates` 409 충돌도 구조적으로 생기지 않는다.

상태는 `data/state.json`, 토큰은 `data/kis_token.json` 에 저장된다
(`STATE_BACKEND=local`, `TOKEN_CACHE=file`).

서버 초기 설정은 스크립트 하나로 끝난다:

```bash
bash infra/ncp/setup.sh
```

시간대 KST 설정 → 파이썬/venv → 의존성 → `cli.py check` 점검 → systemd 등록까지 한다.
`Restart=always` 라 프로세스가 죽어도 10초 뒤 자동으로 다시 뜬다.

```bash
sudo systemctl status ma5-bot
```

```bash
tail -f /opt/ma5-bot/bot.log
```

### 수동 매매 전용으로 돌리기 (대회 조건을 직접 채울 때)

자동매매 없이 텔레그램으로 내가 직접 사고판다. 주문은 한투 OpenAPI 로 나가므로 대회의 'OpenAPI 거래' 로 잡힌다.

```bash
python cli.py manual                       # 텔레그램 /buy /sell ... 만 받는 상주 실행 (스케줄러 없음)
BOT_MODE=manual bash infra/ncp/setup.sh    # 서버에 이 모드로 systemd 등록
```

이미 `serve` 로 떠 있는 서버라면 서비스의 실행 명령만 바꾸면 된다:

```bash
sudo sed -i 's#cli.py serve#cli.py manual#' /etc/systemd/system/ma5-bot.service
sudo systemctl daemon-reload && sudo systemctl restart ma5-bot
```

`serve` 에도 같은 명령이 들어 있어서 자동매매와 같이 써도 된다 (수동 주문은 `state.json` 에 안 남기므로
자동 전략이 그 종목을 팔거나 슬롯으로 세지 않는다. 다만 현금은 같이 쓴다). 같은 텔레그램 봇으로
`serve` 와 `manual` 을 동시에 띄우면 롱폴링이 충돌하니 하나만 띄운다.

텔레그램이 안 될 때는 서버에서 바로:

```bash
# 순서: 종목코드 가격 수량 (가격에 시장가 · m · 0 을 쓰면 시장가)
python cli.py buy 005930 71500 10          # 71,500원에 10주
python cli.py buy 005930 m 1000만          # 시장가로 1,000만원어치
python cli.py sell 005930 72000 5          # 72,000원에 5주
python cli.py sell 005930 m                # 시장가로 전량
python cli.py bal / orders / cancel all / fills / progress
```

## 한투 API 주의점

2025년 이후 규격이 바뀌어서 예전 코드는 그대로 쓰면 주문이 거부된다.

| 기능 | 구버전 | 현재 |
|---|---|---|
| 매수 | `TTTC0802U` | **`TTTC0012U`** |
| 매도 | `TTTC0801U` | **`TTTC0011U`** |
| 정정/취소 | `TTTC0803U` | **`TTTC0013U`** |
| 미체결 조회 | `TTTC8036R` | **`TTTC0084R`** |

- 주문 body 에 **`EXCG_ID_DVSN_CD`** 가 필수로 추가됐다 (NXT 대체거래소 출범).
  `KRX` / `NXT` / `SOR`(최선주문집행) 중 선택하며 기본값은 `KRX`.
- **호가단위**가 2023-01-25 개편으로 코스피·코스닥 통일됐다. 지정가가 호가에 안 맞으면
  주문이 거부되므로 `core/kis/tick.py` 를 반드시 통과시킨다.

  | 가격 | 호가단위 | | 가격 | 호가단위 |
  |---|---|---|---|---|
  | –2,000 | 1 | | 50,000–200,000 | 100 |
  | 2,000–5,000 | 5 | | 200,000–500,000 | 500 |
  | 5,000–20,000 | 10 | | 500,000– | 1,000 |
  | 20,000–50,000 | 50 | | | |

- 토큰은 24시간 유효하고 **재발급은 1분에 1회로 제한**된다. 여러 람다가 각자 발급하면
  제한에 걸리므로 SSM 으로 캐시를 공유한다.
- 유량제한은 실전 계좌 기준 초당 20건(조회), 주문은 초당 1건. 실제로는 더 빡빡하게 걸려서
  `KIS_RATE_LIMIT_PER_SEC` 기본값은 실전 2.5, 모의 1.5 로 잡았다. 유량 오류가 나면 클라이언트가 스스로 더 낮춘다.

### 대회 모드 (STRATEGY=contest)

한 달 안에 +50% (`CT_LOCK_PCT`, 기본 50) 를 한 번 찍을 확률을 노리는 모드다 (평균 수익이 아니다). 근거와 숫자는 `backtest/results/contest_tail_20261002.md`.

| 시각 | 작업 | 내용 |
|---|---|---|
| 08:20 | prep | 월초면 기준 순자산 기록·락 해제. 코스피 시총 200 + 코스닥 시총 150 일봉 캐시 |
| 08:45 | sell_open | 어제 마감에 정한 매도(손절·추적·만료·락·조건용)를 장전 동시호가에 (하한가 지정가 → 시가 체결) |
| 09:05 | check_open | 안 팔린 것은 현재가 −2틱으로 |
| 15:05 | scan | 현재가 350개 → 폭락 판정 → 20일 수익률 상위 10% 중 1위 결정. 폭락 전환이면 보유를 지금 판다 |
| 15:20 | buy_close | 장마감 동시호가 매수 (현재가 + 5틱, 상한가 이내), 순자산 전액 ÷ CT_SLOTS |
| 15:40 | evaluate | 종가로 손절 10% · 추적 10% · 보유 10일 판정, 순자산이 월초 +50% 면 락 → 내일 아침 매도 목록 |

`python cli.py scan` 으로 지금 순위를, `prep` · `sellopen` · `monitor` · `entry` · `close` 로 각 작업을 1회 돌릴 수 있다 (`--force` 는 휴장일 무시).
상태는 `state.json` 의 `contest` 에 둔다. 2020~25 백테스트(락 30): 월 +30% 확률 29%, +20% 34%, −20% 22%, 중앙값 +0.7%. 29거래일 창에서 락 50 은 +50% 확률 24%, +30% 31%, −30% 14%.

## 알아둘 것

- **09:05 판정은 5분치 데이터만 보고 내린다.** 오전에 5일선을 넘었다가 종가에 다시
  깨지는 속임수(whipsaw)가 구조적으로 존재한다. 이를 줄이려면 판정을 장 후반으로
  미뤄야 하는데, 그러면 당일 상승분을 놓친다. 지금은 즉시성을 택한 설정이다.
- **백테스트는 돌리지 않았다.** `+10%` `3거래일` `5일 중 3일` 같은 숫자는 합의된 규칙이지
  검증된 최적값이 아니다. 전부 `config.py` 와 `.env` 로 조정 가능하게 열어뒀다.
- **익절 3% 는 마찰비용을 감안한 하한선에 가깝다.** 왕복 한 번에 매도세 0.15% + 수수료 –0.03% +
  슬리피지(진입 +2틱, 청산 −1–2틱) 0.3–0.7% 가 나간다. 1% 였으면 수익의 절반 이상이 비용이다.
- **3% 익절은 손익비를 뒤집는다.** 이길 때 +3% 고정, 질 때 5일선 이탈(보통 −2–4%, 갭이면 −5–10%).
  대략 1:1 이라 승률 55% 는 나와야 남는다. 갭하락 한 방이 익절 세 번치다 — 손절 없이 돌린다는 게
  이 구조에서 더 무거운 결정이 된다.
